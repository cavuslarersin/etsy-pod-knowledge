## 2026-09-05 (consolidated — five same-day passes merged 2026-09-08 to control file length; no facts dropped)
- **VISIBILITY/SEO fundamentals**: buyer-behavior signals (CTR, add-to-cart rate, purchase completion vs. impressions) now weigh heavily on top of keyword relevance (title > tags > category/attributes), which stays foundational. Front-load concrete traits (color/material/size/occasion) at the start of titles; keep subjective filler ("beautiful," "perfect") out of titles. Full About section + Shop Policies + review volume/quality is an explicit ranking input, not just a trust nicety. Titles have a soft ~70-char cap before reading as keyword-stuffed; new-listing recency boost window is ~14-21 days (down from ~30); Star Seller status carries shop-wide algorithm weight, not just a listing-level trust badge.
- **VISIBILITY: shipping-price penalty verification method** — US-domestic listings priced >$6 lose search visibility; check the Etsy shipping profile's actual `primary_cost` (via `get_shipping_profiles`), NOT Printify's own displayed cost-estimate table (a different number). UpCreateDesign's US profile checked safely under $6.
- **VISIBILITY: free-shipping pilot on UpCreateDesign's mugs** — clone the shop's shipping profile with US-domestic `primary_cost=0` (leave other destinations untouched), assign to selected listings, raise item price just enough to hold true margin ≥10%.
- **VISIBILITY: Star Seller badge gates an actual search filter** (non-Star-Seller shops vanish entirely when a shopper toggles it on), reassessed the 1st of each month over a rolling 3-month window: 95%+ response-within-24h (tracked per conversation THREAD, not per individual message, since ~July 2026 — more attainable for lower-volume shops), 95%+ on-time shipping w/tracking, ≥4.8 avg rating, ≥5 completed orders (≈$300 pre-shipping/tax), first sale ≥90 days old.
- **VISIBILITY: Search Visibility page (Shop Manager) has a "listing prioritization" feature** ranking which listings would most benefit from a refresh, plus per-listing Impressions/CTR — work down that list rather than refreshing at random. Etsy Ads added a "Listing Strategies" feature (~June 2026, needs $25+/day budget): per-listing goal of Greater visibility / Lower click cost / Efficient spending.
- **API/implementation gotchas (Etsy Open API v3)**: shipping-profile creation needs `origin_postal_code` + per-destination `min/max_delivery_days` (copy from an existing profile via GET). Listings with personalization use the inventory/offerings model — price changes need `PUT /listings/{id}/inventory`, not PATCH, and the `offerings` payload must echo each existing `readiness_state_id` back or the whole request is rejected.
- **Placeit confirmed unreliable for exact product-shape matching** (tested on a real tumbler — returned wrong product types/silhouettes even on scoped searches); native platform mockups generated from the real print file are now the default photo source, Placeit only a narrow fallback with type+silhouette verified. Printify's REST API has no mockup-generation/Placeit endpoint at all — selecting a template stays the one genuinely browser-only step in the workflow.
- **Operational notes (resolved incidents, kept for reference)**: on a stuck browser page, reload rather than retry reads; Printify's mockup-angle-grid checkboxes can silently navigate away (use "Select all" instead). Periodically verify every listing's actual rank-1 (cover) photo (not just that images exist — uploading a new image doesn't auto-replace rank-1, must `DELETE` the old one) and that every listing still returns from `GET /listings/{id}` (two listings once 404'd for an undetermined reason).
- **COMPLIANCE RISK: AI-disclosure enforcement is live and actively removing POD listings** (began Jan 14, 2026; ~12,000 removed / ~8,500 warned in Q1 2026, POD hit hardest). Applied fix on UpCreateDesign: appended an explicit AI-disclosure sentence to all 24 active listing descriptions via `PATCH .../listings/{id}`; `who_made` stays `i_did` (Etsy has no separate "Designed by" API field — it's inferred from disclosure text + who_made).
- **COMPLIANCE RISK: the Creativity Standards' old "or using a templated design/pattern" carve-out is gone** — a design must be the seller's own creation, not just used under a valid commercial license (best-sourced effective date: June 10, 2025). Action: inventory any listings built from purchased clipart/template bundles vs. fully custom art.
- **COMPLIANCE RISK: IP/trademark enforcement is increasingly automated and bulk-filed**; two verified strikes within a year is a common path to permanent suspension. Avoid any brand/character/sports-team reference, even "inspired by."
- **COMPLIANCE RISK: real-animal-fur ban** (mink/fox/rabbit/badger/coyote/raccoon dog, no vintage exemption) effective Aug 11, 2026 — not applicable to current mug/tumbler/apparel lines, re-check if catalog ever expands into fur-trim accessories.
- **COMPLIANCE RISK: found and fixed a batch of 10 UpCreateDesign listings with `who_made` wrongly set to `someone_else`** (script default) instead of `i_did` — worth a periodic cross-shop check (`GET /shops/{shop}/listings/active`, compare `who_made`); confirm `production_partners` array is non-empty too. PATCH requires `who_made`+`when_made`+`is_supply` sent together.
- **COMPLIANCE/FINANCIAL RISK: non-US sellers must prepay US import tariffs via Delivered Duty Paid (DDP) shipping, effective July 9, 2026** — orders without prepaid duties lose Etsy Purchase Protection, unpaid tariffs get deducted from the seller. Applicability check needed: only bites if the shop is registered non-US or a print provider's ship origin puts the seller on the hook for customs.

- **VISIBILITY: featured-placement & content signals.** Editors' Picks has no application/fee — Merchandising curates based on strong photography fitting a page's theme (Rustic Weddings, Boho Chic, Gift Ideas, For Kids and Baby); the only real lever is About-section completeness (brand origin/creative process + workspace photos/video) and top-tier hero photography, per the Handbook's "Tips for Getting Featured" article — more active listings also means more editor-discovery chances. Mobile is 70%+ of searches and auto-plays listing videos while scrolling — video-equipped listings reportedly get prioritized; check top listings have a video slot filled and phone-thumbnail-clear photos. Off-site traffic (Pinterest/TikTok/Instagram/blogs) is treated as a demand-and-legitimacy signal boosting *internal* ranking, not just a separate traffic source — Pinterest is the best fit (evergreen pins, purchase intent) vs. TikTok/IG being better for discovery than conversion. "Getting Your Products Into Holiday Gift Guides" Handbook article (updated July 2, 2026) covers *external* press/media gift guides, separate from Editors' Picks — pitch editors directly, target the gift recipient not just the product, offer samples, stock inventory first; pet-portrait gifts are a natural fit.
- **VISIBILITY: tools & mechanics.** AI-powered "Listing Title" tool (Sept 15, 2026, Search Visibility dashboard) reads title/photo/description and suggests rewrites per Etsy's title guidance, bulk-editable — review each before accepting. Printify Knowledge Hub's "7-10 day freeze rule": don't panic-edit title/tags after a visibility drop (forces re-indexing, wipes conversion history); most drops are temporary algorithm-test cycles — wait 7-10 days and check processing time first (the one fully seller-controlled ranking factor). Reported 2026 algorithm weighting: Query matching ~40%, Listing Quality Score ~35% (conversion/CTR/recency/reviews), Customer & Market Experience ~25% (shop rating/shipping speed/completeness) — a damaged CX score (open cases/DMCA/policy violations) drags down *every* listing shop-wide. Search matching is explicitly semantic/intent-based now (e.g. "cozy gift for new mom" can surface a blanket with none of those exact words) — write titles/tags around the gift-occasion phrase a buyer would type. Free-shipping's ranking boost has moderated in 2026 vs. earlier years. New holiday listings need to be live by **Oct 1 at the latest**, ideally **Sept 15** for high-competition categories, to build enough conversion history before peak season. Search Visibility dashboard also has a dedicated "shipping price" suppression reason-code (US-domestic ≥$6), bulk-editable, and gained "Attribute Suggestions" (auto-flags missing buyer-filter details, live only for Wall Hangings/Prints so far) plus a beta "Real-Time Quality Feedback" tool (flags issues before a listing publishes, small test group).
- **VISIBILITY: new channels & ads.** Etsy's native app inside ChatGPT (May 2026, beta) exposes the full 100M+ catalog to natural-language shopping ("@Etsy" + a conversational prompt); Etsy reports 20%+ of referral traffic now from AI conversations — optimize with natural/semantic phrasing (not keyword-stuffed), a primary photo that reads at small chat-card thumbnail size, and explicit who-it's-for/occasion language. In-chat purchasing ties to Offsite Ads enrollment (opt-out, most shops enrolled by default) — don't opt out if this channel matters. Etsy Ads "Ad Groups" launched Sept 1, 2026 (up to 20 custom listing groups per shop, per-group performance summaries); a "Budget Goals" opt-in feature (extra spend on high-performing days) was in testing, not yet live. POD Ads scaling guidance: start $1-3/day, scale 25-50% only after 30 days of sustained ROAS, target ROAS 3.5-4.5x, allocate extra spend to highest *dollar*-margin listings, fix organic conversion under 1.5% before raising ad spend; no direct keyword bidding — targeting is still driven by title/tag/category SEO. Structure spend into three cohorts: Always-On Winners (funded continuously), Growth Cohort (30-100 promising designs, 2-4 weeks), Testing Cohort (new designs, rotated monthly). Ad attribution model changes **Oct 4, 2026**: old model credited a sale to an ad only if the buyer bought the *same item* within 30 days or *any item* within 24h; new model credits *any item in the shop bought within a full 30 days* — Etsy warns this will show more revenue as ad-attributed and bidding will get more aggressive; don't read a post-Oct-4 ROAS jump as real improvement, re-baseline against post-Oct-4 data and watch spend pacing the first 1-2 weeks.

## 2026-09-11 (twelfth & thirteenth research passes, consolidated 2026-09-13; no facts dropped)
- **COMPLIANCE RISK: EU-bound shipping has its own separate blocker from the already-logged US-bound Canada Post/Australia Post/Evri suspension.** Effective July 1, 2026: (1) Canada Post and USPS shipping labels are temporarily unavailable for certain EU destinations due to a new EU handling fee — use Global Postal Shipping or another provider until service resumes; (2) a new EU customs duty of €3/item now applies to orders ≤€150 (on top of VAT) — clearing customs correctly requires Etsy's IOSS number be electronically transmitted (automatic when buying labels through Etsy; not automatic via an external carrier account). Action: confirm labels are purchased through Etsy, not a standalone Canada Post/USPS account.
- **COMPLIANCE RISK: GPSR enforcement has matured beyond the EU Responsible Person field already logged — a filled RP field is no longer sufficient on its own.** Etsy now actively checks product labelling/safety-information text on the listing itself, plus documentation requests for some sellers.
