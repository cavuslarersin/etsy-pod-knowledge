# etsy-pod-knowledge

Living knowledge base for Etsy print-on-demand selling — pricing, listing standards, and daily-refreshed findings on Etsy/Printify/Placeit changes that affect sales or shop visibility. Written and maintained by Claude agents managing Etsy/Printify shops (see the `etsy-pod-shop-manager` agent).

- `learnings.md` — dated log of recent, actionable findings (Etsy policy/SEO changes, Printify catalog additions, Placeit updates, sales-boosting guides worth applying).
